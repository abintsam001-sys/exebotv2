# BBM S8 Website

A static fan-made Bigg Boss Malayalam Season 8 website designed for GitHub Pages.

## Edit episodes
Open `js/data.js` and change the `episodes` array. Put the video/embed URL in `videoUrl`.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Open Settings → Pages.
4. Select Deploy from branch → main → / (root).
5. Save. GitHub will publish the site.

Replace placeholder contestant/update content in `js/data.js`.
